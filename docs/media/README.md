# docs/media

Folder reserved for images and GIFs of the project. It is empty on purpose: the README files do not show any capture yet.

Carpeta reservada para imágenes y GIF del proyecto. Está vacía a propósito: los README todavía no muestran ninguna captura.

When you add one / Cuando añadas una:

- Use the sample table, never real data. / Usa la tabla de ejemplo, nunca datos reales.
- GIF: at most 1280 px wide and under 8 MB. / GIF: 1280 px de ancho como máximo y menos de 8 MB.
- Reference it from both `README.md` and `README.es.md`. / Referénciala en los dos README.
