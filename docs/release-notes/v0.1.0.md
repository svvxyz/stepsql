# StepSQL 0.1.0

**English** · [Español](#español)

First public version of StepSQL, an educational tool that shows how the data changes at every stage of the logical processing order of a T-SQL (SQL Server) query.

**Try it:** https://svvxyz.github.io/stepsql/

### What you can do

- Write a single-table `SELECT` and follow it stage by stage: `FROM`, `WHERE`, `GROUP BY`, aggregates, `HAVING`, `SELECT`, `DISTINCT`, `ORDER BY`, `TOP` and the result.
- See why every row passes or is discarded, how the groups are formed, how each `COUNT`, `SUM`, `AVG`, `MIN` and `MAX` is computed (with the ignored `NULL`s) and which columns reach the result.
- Hover a row to see which rows of the source table it comes from.
- Watch an animation for each stage, at three speeds, or show all the steps at once.
- Edit the 50-row sample table or create your own tables.
- Get errors with the SQL Server error number (8120, 147, 207, 208…), underlined in the query.
- Use it in English or Spanish, in light or dark theme, and in projector mode for class.

### Not included yet

`JOIN` and several tables, subqueries, `UNION`, `CASE`, scalar functions such as `UPPER` or `ISNULL`, window functions, `ROLLUP` / `CUBE` / `GROUPING SETS`, `TOP … WITH TIES`, `OFFSET … FETCH` and CSV / JSON import. StepSQL says clearly when a query uses one of them. `JOIN` is planned for 1.0.

StepSQL shows the logical order that defines the result, not SQL Server's physical execution plan.

The full list of changes is in [CHANGELOG.md](https://github.com/svvxyz/stepsql/blob/v0.1.0/CHANGELOG.md). The attached `stepsql-v0.1.0.zip` is the compiled static site: unzip it and serve it with any static web server.

## Español

Primera versión pública de StepSQL, una herramienta educativa que muestra cómo cambian los datos en cada etapa del orden lógico de procesamiento de una consulta T-SQL (SQL Server).

**Pruébala:** https://svvxyz.github.io/stepsql/

### Qué puedes hacer

- Escribir un `SELECT` sobre una tabla y seguirlo etapa por etapa: `FROM`, `WHERE`, `GROUP BY`, agregados, `HAVING`, `SELECT`, `DISTINCT`, `ORDER BY`, `TOP` y el resultado.
- Ver por qué cada fila pasa o se descarta, cómo se forman los grupos, cómo se calcula cada `COUNT`, `SUM`, `AVG`, `MIN` y `MAX` (con los `NULL` ignorados) y qué columnas llegan al resultado.
- Pasar el ratón por una fila para ver de qué filas de la tabla original viene.
- Ver una animación de cada etapa, a tres velocidades, o mostrar todos los pasos a la vez.
- Editar la tabla de ejemplo de 50 filas o crear tus propias tablas.
- Recibir errores con el número de error de SQL Server (8120, 147, 207, 208…), subrayados en la consulta.
- Usarla en español o en inglés, con tema claro u oscuro, y en modo proyector para clase.

### Todavía no incluye

`JOIN` y varias tablas, subconsultas, `UNION`, `CASE`, funciones escalares como `UPPER` o `ISNULL`, funciones de ventana, `ROLLUP` / `CUBE` / `GROUPING SETS`, `TOP … WITH TIES`, `OFFSET … FETCH` ni la importación de CSV / JSON. StepSQL avisa claramente cuando una consulta usa alguna de estas cosas. `JOIN` está previsto para la versión 1.0.

StepSQL muestra el orden lógico que define el resultado, no el plan de ejecución físico de SQL Server.

La lista completa de cambios está en [CHANGELOG.md](https://github.com/svvxyz/stepsql/blob/v0.1.0/CHANGELOG.md). El archivo adjunto `stepsql-v0.1.0.zip` es el sitio estático compilado: descomprímelo y sírvelo con cualquier servidor web estático.
